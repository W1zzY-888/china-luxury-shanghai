# China Lux Shanghai

Демонстрационная концепция сайта авторских экскурсий Кати в Шанхае.

Статический сайт: HTML, CSS и JavaScript. Для запуска откройте index.html или запустите `python3 -m http.server 8000`.

Демо-админка: `#admin`. Туры и тестовые заявки хранятся только в localStorage текущего браузера. Нет серверной базы, авторизации или отправки заявок. Не вводите реальные клиентские данные.

Тексты и маршруты требуют согласования. Авторы фотографий и лицензии указаны в credits.html.

Дизайн обновлён 4 октября 2026: тёмная палитра, золото, предоставленный логотип, мобильное меню. Подробные каталоги ожидают материалов заказчика.
